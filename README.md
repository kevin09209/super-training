# Super Training 健身課表 APP

依你的年齡、身高、體重、臥推／引體／深蹲 1RM、訓練時間、部位與強度，自動安排重訓或有氧課表的 PWA（網頁 APP）。資料只存在裝置本機，不需要帳號。

## 功能

- **今日課表產生器**：輸入時間、部位、重訓／有氧、強度，依所選地點的器材自動安排動作，含熱身組、組數、次數、建議重量、組間休息與 RPE。
- **超級組**：允許時會自動把拮抗肌或互不干擾的輔助動作配成超級組，省時間、多動作。
- **動作替換**：每個動作都可一鍵換成同肌群的其他動作，只列出該地點做得到的。
- **每週計畫**：選 2–6 天，自動用全身／推拉腿／上下肢分化排整週，每天都可個別重排或替換。
- **訓練中紀錄**：逐組填實際重量與次數、打勾完成，自動開始組間休息倒數（提示音＋震動）。
- **1RM 追蹤**：手動輸入或用「重量 × 次數」推算；訓練完成後若推估出新 PR 會提示更新，並以折線圖顯示進度。
- **多個訓練地點**：預設商業／公司／社區健身房三種器材組合，可自由編輯或新增。
- **匯出／匯入備份**：換手機時用 JSON 檔搬資料。

## 動作庫

`src/data/exercises.ts` 收錄約 100 個動作，依網路上普遍共識分成三級：

- **tier 1（CP 值高）**：槓鈴臥推、啞鈴臥推、雙槓撐體、引體向上、滑輪下拉、槓鈴／啞鈴划船、硬舉、槓鈴肩推、側平舉、面拉、深蹲、腿推、哈克深蹲、保加利亞分腿蹲、羅馬尼亞硬舉、腿彎舉、槓鈴臀推、窄握臥推、繩索下壓／過頭伸展、EZ 槓／啞鈴／錘式／上斜彎舉、懸垂舉腿、繩索捲腹、小腿機等。
- **tier 2**：常用主力輔助動作。
- **tier 3**：補充或器材受限時的替代動作。

每個動作標註主要／次要肌群、所需器材、複合／孤立，以及相對於三大基準 1RM 的估算比例（例如上斜臥推 ≈ 臥推 0.8、滑輪下拉 ≈ 引體總負荷 0.85、腿推 ≈ 深蹲 1.6）。比例僅供起始參考，實際以 RPE 調整。

## 強度對照

| 強度 | %1RM（複合／孤立） | 次數 | 組數 | 組間休息 |
| --- | --- | --- | --- | --- |
| 輕鬆 / 肌耐力 | 62% / 55% | 12–15 / 15–20 | 3 | 75s / 45s |
| 中等 / 增肌 | 72% / 65% | 8–10 / 10–15 | 4 / 3 | 120s / 60s |
| 高強度 / 肌力 | 82% / 72% | 4–6 / 8–10 | 4 / 3 | 180s / 90s |

有氧依強度分別安排 LISS（低）、2 分快／2 分慢間歇（中）、30 秒全力／60 秒緩和 HIIT（高），並依年齡給出心率區間。

## 開發

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # vitest 單元測試
npm run build    # 型別檢查 + 打包到 dist/
```

## 部署到 GitHub Pages

1. 把程式合併到 `main`。
2. GitHub repo → Settings → Pages → Source 選 **GitHub Actions**。
3. `.github/workflows/deploy.yml` 會在每次 push 到 `main` 時自動測試、打包並部署到 `https://<帳號>.github.io/super-training/`。

## 安裝到手機主畫面

- **iPhone**：Safari 開啟網址 → 分享 → 加入主畫面。
- **Android**：Chrome 開啟網址 → 右上選單 → 安裝應用程式（或「加到主畫面」）。

安裝後可離線使用，資料存在該裝置的瀏覽器裡；清除瀏覽器資料會一併清除，請定期在「設定」匯出備份。
